# Full-Stack AI Project Brief

Build a small application that connects a user interface, API, model, and data store. Include evaluation and deployment notes from the start.

## Minimum deliverables

- A clear user problem and a narrow feature scope.
- Frontend and API service with a documented request flow.
- Model/provider configuration isolated from source code.
- Tests or evaluation examples for representative inputs.
- Deployment instructions, costs, privacy, and known limitations.

Use the [LLM Engineering track](../../curriculum/03-ai-systems/README.md) and [AI-Assisted Building track](../../curriculum/06-ai-assisted-building/README.md).
