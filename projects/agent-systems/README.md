# Agent Workflow Project Brief

Build a bounded workflow or tool-using agent that completes one well-defined task. Prefer explicit steps, narrow tool permissions, and human approval for consequential actions.

## Minimum deliverables

- A task definition and clear stopping conditions.
- Tools with documented inputs and permissions.
- Logs of tool calls and outcomes.
- Evaluation cases for success, failure, and unsafe or ambiguous inputs.
- Human review points and recovery behavior.

Use the [Agents & Workflows track](../../curriculum/05-agents-workflows/README.md). Do not provide real credentials or broad access to an agent during experimentation.
