# RAG Chatbot Project Brief

Build a small application that answers questions from a user-provided document set and shows which retrieved sources support each answer.

## Minimum deliverables

- Document ingestion and a clearly described chunking strategy.
- A retrieval step and a model response step.
- Source citations or excerpts in the UI.
- A small evaluation set with expected answers and failure cases.
- Setup instructions, privacy notes, costs, and known limitations.

Use the [RAG & Context Engineering track](../../curriculum/04-rag-context/README.md) and the [resource map](../../docs/RESOURCE_MAP.md) for upstream leads. Do not upload private documents to a provider without permission.
