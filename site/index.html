THE IDEA 01

Go beyond the prompt.
Build the product.

AI tools are changing how software gets imagined, built, and operated. The AI-Bootcamp outline connects the foundations to the craft: model APIs, retrieval, agents, product architecture, evaluation, and deployment.

Learn to use coding assistants with intention, understand the systems they help create, and keep people in control of the result.

THE CURRICULUM 02

Six tracks. From foundations to agents.

Open a track to explore the lesson map, from Python and machine learning through production systems, RAG, and agent workflows.

＋ Select a track to see lesson details

01FOUNDATIONSAI / ML FoundationsBuild core code and concepts, from Python to your first machine learning model.+
  1. Python Essentials for AI EngineeringData structures, functional patterns, typing, JSON, pathlib, NumPy and Pandas.
  2. Mathematics is the Language of AILinear algebra, calculus and probability through practical Python examples.
  3. Start Simple: Linear ModelsBuild and evaluate an interpretable regression baseline with real data.
  4. Essential PyTorchTensors, autograd, data loading, optimizers and complete training loops.
02MLOPSProduction ML SystemsMove from exploratory notebooks to repeatable data, training and serving pipelines.+
  1. Understanding Your DataExplore distributions, missing values and outliers with Pandas and Seaborn.
  2. Data Validation and PipelinesUse Pandera, scikit-learn Pipelines and DVC to make preprocessing reliable.
  3. Reproducible TrainingBuild DVC pipelines, track experiments in MLflow and tune LightGBM models.
  4. Model to ServiceServe a trained model with FastAPI and package it with Docker.
  5. Cloud Deployment with AWSWork with S3, ECR, ECS and EC2 deployment building blocks.
03AI SYSTEMSLLM EngineeringBuild capable applications with model APIs, local models, tools and evaluation.+
  1. Run Models LocallyGet started with Ollama for private, local AI development.
  2. Prompt EngineeringUse a structured prompt template to improve model instructions.
  3. APIs, Structured Output and ToolsConnect model calls to application logic and typed responses.
  4. LangChain FoundationsBuild prompts, Pydantic outputs and a small document RAG pipeline.
  5. Model Context ProtocolCreate Python MCP servers and clients, then build a practical todo agent.
  6. Dataset DistillationUse a teacher model to label data for specialized training and evaluation.
  7. Automated Prompt EngineeringExplore DSPy optimization for a sentiment-analysis workflow.
  8. Evaluating LLMsMeasure quality and reliability rather than relying on impressions.
  9. Fine-Tuning LLMsFollow a QLoRA workflow from data preparation to evaluation and Hub deployment.
04RAG & CONTEXTKnowledge for ModelsConnect LLMs to relevant documents and improve the context they receive.+
  1. Build a Chatbot with MemoryCreate a conversational wellness-coach prototype with LangChain and Streamlit.
  2. Cache-Augmented GenerationBuild a local CAG system with LangChain and Ollama.
  3. Document ProcessingExtract structured knowledge from PDFs, including images and tables.
  4. Effective ChunkingCompare structure-aware, semantic and model-assisted chunking strategies.
  5. Embeddings and Vector SearchCreate semantic search with embeddings and Supabase pgvector.
  6. Retrieving the Right ContextCombine BM25, vector search, reranking and query reformulation such as HyDE.
  7. Build a RAG SystemBring document processing, hybrid search and a local LLM together.
05AGENTS & WORKFLOWSOrchestrate AI WorkDesign stateful workflows and agents that use tools to complete multi-step tasks.+
  1. LangGraph: Workflows and AgentsBuild a support-ticket system and compare controlled workflows with flexible agents.
  2. Agentic WorkflowAnalyze Reddit posts and generate a report using local models.
  3. Talk to Your DatabaseBuild a database agent with a local LLM, LangChain and Ollama.
  4. Local MCP Knowledge AgentMake a local-first assistant that can chat with personal files.
  5. Agentic RAG Analyst TeamCoordinate retrieval from market APIs and SEC filings for finance questions.
06AI-ASSISTED BUILDINGFrom Prototype to ProductUse coding assistants to build full-stack applications and explore SaaS ideas.+
  1. Cursor AI and Coding AssistantsPlan changes, manage context and review generated code with care.
  2. Rapid PrototypingExplore tools such as v0, Replit and simplified backend services.
  3. Full-Stack AI ApplicationsCombine a frontend, model API, data store and deployment workflow.
  4. LLMOps in PracticeBring together testing, evaluation, observability and iteration.
