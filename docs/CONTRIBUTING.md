# Contributing

Contributions that make the learning path clearer, more accurate, and easier to practice are welcome.

## Good contributions

- Improve a track guide or add a small original exercise.
- Add a well-maintained upstream resource with a direct link, track, and short reason for inclusion.
- Fix an outdated link, unsupported claim, accessibility issue, or setup instruction.
- Add a project brief with explicit prerequisites and a testable outcome.

## Resource attribution and licensing

Before copying any third-party material, verify its current license and terms. Keep required copyright and license notices, record the upstream repository and commit, and include attribution in the relevant guide. Do not copy unlicensed material, course slides, datasets, or student work without permission. When reuse rights are unclear, link to the source instead.

## Pull request checklist

- Explain the learner problem your change addresses.
- Link to the upstream source and identify its license when adding external material.
- Keep instructions reproducible; do not commit credentials or private data.
- Check headings, links, keyboard navigation, and mobile layout for site changes.
