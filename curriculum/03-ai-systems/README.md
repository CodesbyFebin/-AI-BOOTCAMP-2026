# AI Systems: LLM Engineering

Connect model providers and local models to application code; learn prompts, structured outputs, API design, evaluation, and application architecture.

## Suggested learning sequence

1. Start with the concepts and prerequisites in the linked source guides.
2. Reproduce one small example and record the environment and data used.
3. Change one input or design choice; explain how the result changes.
4. Write a short reflection covering limitations, failure cases, and next steps.

## Learning outcomes

- Explain the core concepts in this track in your own words.
- Build or reproduce a small working artifact.
- Identify at least one limitation and one way to test quality.
- Cite upstream material and distinguish your original work from adapted examples.

## Practice brief

Create a small portfolio artifact for this track. Include a README with its purpose, setup, data or model assumptions, evaluation method, known limitations, and links to references. Do not publish keys, private data, or material you do not have permission to redistribute.
